First, the goods are returned from the end customer into consignment stock using sales order type ZCKR. If the material must then continue further back to the original point of origin (the physical location used in the original supply routing), this is performed as an Export Consignment Pick-up. Note that a pick-up cannot be routed to an SAP plant code with a different VAT than the country it is shipping to - for example, a return to Belgium requires a Belgium VAT plant code to be present in the original supply routing.",
