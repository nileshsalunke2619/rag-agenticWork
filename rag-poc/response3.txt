Locating the Plant Code in Material Master (MM03)
Organizational Levels Screen
Based on the retrieved context, the plant code is entered on the 'Organizational Levels' screen within the Material Master (transaction MM03). After selecting the desired view(s) for a material, the system presents an Organizational Levels pop-up where you specify the Plant field (along with other organizational data such as Sales Org. and Distribution Channel, if applicable). This plant code should correspond to the routing you are working with, and after entering it you continue into the material master view — for example, the 'Foreign Trade: Export Data' view, where the HS Code appears under 'Comm./imp. code no.'
Steps:
Go to transaction MM03 – Material Master Data and enter the material number
Select the required view(s), such as Foreign Trade: Export Data
On the Organizational Levels screen, enter the plant code as per your routing under the 'Plant' field
Continue to proceed into the selected view, where related data (e.g., HS Code under Comm./imp. code no.) can be reviewed
